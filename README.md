### Hi, I'm Marcos 👋

Senior Software Engineer, Release & Reliability at [Nethermind](https://github.com/NethermindEth), based in Buenos Aires.

I run releases for the [Nethermind execution client](https://github.com/NethermindEth/nethermind). Nothing reaches node operators until it has passed our soak fleets on mainnet, Gnosis, Sepolia, Hoodi and OP networks. Most days that means:

- **Release engineering:** release branches, backports, smoke-test triage, and separating real client bugs from CI noise.
- **Test infrastructure:** Terraform-managed node fleets on GCP, self-hosted CI runners, and Prometheus/Loki dashboards with alerts for stalls and memory.
- **Fork days:** live monitoring of every node's health and chain agreement during network upgrades.
- **Client fixes:** sync, pruning, txpool, networking and JSON-RPC hardening.
- **AI tooling for the team:** LLM pull-request review in CI, and routing CI failures to the engineer responsible.

Before that I was one of the first engineers on [Juno](https://github.com/NethermindEth/juno), Nethermind's Starknet full node in Go, and I've worked on [Sedge](https://github.com/NethermindEth/sedge), a one-command node and validator setup tool.

**Public numbers:** 118 merged PRs in `nethermind`, 104 in `sedge` and 32 in `juno`, plus 250+ PR reviews in `nethermind`.
